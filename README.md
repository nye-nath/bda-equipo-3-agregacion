## 1. Descripción del Ejemplo y Caso de Uso Real

* **`aggregatewordcount`**: Cuenta la frecuencia de las palabras en un texto utilizando la librería de agregación de Hadoop.
* **`aggregatewordhist`**: Genera un histograma de frecuencias indicando cuántas palabras ocurren exactamente N veces.
